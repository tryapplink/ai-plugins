# Applink AI plugins

Plugins that connect AI assistants to [Applink](https://tryapplink.com), where a team's internal apps, integrations and databases live. Each folder is one assistant's plugin. They share the same skill, which teaches the assistant how Applink apps work, and the same connector.

| Folder | For |
| --- | --- |
| [claude](claude) | Claude: claude.ai, Claude Desktop, Cowork and Claude Code |

## Install in Claude Code

```bash
claude plugin install applink --marketplace tryapplink/ai-plugins
```

This repository is written from Applink's own, so changes made here are overwritten. Documentation: https://tryapplink.com/docs/claude
